# Phi

<img width="512" height="512" alt="logo" src="https://github.com/user-attachments/assets/4ad265e2-04ba-4973-b951-f661d15647ec" />

A minimal, fast terminal emulator built with Electron — designed to stay out of your way.

## Features

- Powered by `node-pty` and `xterm.js` for native shell performance
- Custom titlebar with macOS-style window controls
- Fully themeable — colors, fonts, cursor style, and more
- Settings panel with live preview
- Intro splash screen (optional)
- Scrollback history up to 100,000 lines
- Clean black-first aesthetic
